🎓 ระบบบริหารโครงการพัฒนาบุคลากร

กำหนดกระบวนการ มอบหมายงาน
และติดตามความคืบหน้า — ร่วมกันทั้งทีม

แอปเว็บสำหรับทีม HRD ใช้กำหนดขั้นตอนมาตรฐาน สร้างโครงการ มอบหมายผู้รับผิดชอบ ติดตามกำหนดส่ง และรับการแจ้งเตือนแบบ realtime ข้อมูลเก็บกลาง ทุกคนเห็นตรงกัน

🚀 เปิดแอปทีม 🧪 ลอง Demo ก่อน

สิ่งที่ระบบทำได้

ออกแบบมาสำหรับงานพัฒนาบุคลากร ตั้งแต่สำรวจความต้องการจนถึงประเมินผลฝึกอบรม

⚙️

แม่แบบกระบวนการ

กำหนดขั้นตอน ระยะเวลา บทบาท หลักฐาน และ dependency แล้วนำไปใช้สร้างโครงการซ้ำได้

👥

มอบหมายงาน

เลือกผู้รับผิดชอบและกำหนดส่ง ระบบแจ้งเตือนเมื่อกดบันทึก (แก้เป็นร่างก่อน ยังไม่แจ้งเตือนทันที)

📊

ติดตามความคืบหน้า

ดู Checklist, Kanban และแถบความคืบหน้า พร้อมบล็อกขั้นตอนที่รอต้นทางอัตโนมัติ

🔔

แจ้งเตือน

แจ้งเมื่อถูกมอบหมาย เปลี่ยนสถานะ ใกล้กำหนด หรือเลยกำหนด พร้อมกันซ้ำ (dedupe)

⚡

ทำงานร่วมกันสด

ข้อมูลเก็บใน Supabase ทุกการแก้ไขอัปเดตให้สมาชิกทุกคนแบบ realtime ไม่ต้อง refresh

🧾

Audit trail

บันทึกประวัติทุกการเปลี่ยนแปลง ใครทำอะไรเมื่อไหร่ ตรวจสอบย้อนหลังได้ทันที

เริ่มใช้งานในทีม

ตั้งค่าครั้งเดียว หลังจากนั้นทุกคนเปิด URL เดียวกันได้เลย

  1. สร้าง Supabase สร้างโปรเจกต์ที่ supabase.com แล้วรันไฟล์ supabase/schema.sql ใน SQL Editor
  2. ใส่ config ว่าง Project URL และ anon key ใน app/config.js แล้ว commit ขึ้น main
  3. แจ้งทีม ส่งลิงก์ https://pumisa-cloud.github.io/project/ ให้เพื่อน แล้วให้แต่ละคนเลือกชื่อตัวเอง
  4. เริ่มทำงาน สร้างโครงการจากแม่แบบ มอบหมายงาน แล้วกด 💾 บันทึก — ทุกคนเห็นตรงกันทันที
💡 ยังไม่ได้ใส่ config? แอปจะเปิดใน โหมดท้องถิ่น (เก็บข้อมูลในเบราว์เซอร์) และมีปุ่ม ตั้งค่า Supabase ให้ลองใส่ค่าได้ทันที
