# Demo แบบกดได้ทันที (ไม่ต้องติดตั้ง Node.js)

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือใช้ **Review pane** ของ OpenCode
(ข้อมูลจำลองเก็บใน `localStorage` และมีปุ่ม **รีเซ็ตข้อมูลตัวอย่าง** ด้านซ้าย)

ใช้ธีมสีมหาวิทยาลัยขอนแก่น (KKU Maroon `#A73B24`) พร้อมปรับ UI ให้อ่านง่ายขึ้น:
การ์ดสรุปมีไอคอน ปุ่มมีสถานะ hover/focus แถบแจ้งเตือนและข้อความยังไม่บันทึกใช้สีเน้น
และรองรับหน้าจอแคบ (responsive)

## ข้อมูลตัวอย่าง: โครงการด้านการพัฒนาบุคลากร (HRD)

ผู้ใช้จำลอง:

| ผู้ใช้ | บทบาท | แผนก |
|---|---|---|
| สมชาย | Admin | HR |
| มาลี | Project Manager | HRD |
| ธนา | Training Officer | HRD |
| จินดา | Line Manager | Operations |
| ผู้บริหาร | Viewer | Exec |

แม่แบบกระบวนการ:

1. **กระบวนการพัฒนาบุคลากรประจำปี** — สำรวจความต้องการฝึกอบรม → วิเคราะห์ช่องว่างทักษะ → จัดทำแผน → ขออนุมัติ → คัดเลือกวิทยากร → ฝึกอบรม → ประเมินผล → สรุปรายงาน
2. **กระบวนการ Onboarding พนักงานใหม่** — เตรียมเอกสาร → ปฐมนิเทศ → แนะนำทีม → ฝึกทักษะ → ติดตาม 30 วัน → ประเมินทดลองงาน

โครงการตัวอย่าง:

- **HR-2569-001** โครงการพัฒนาทักษะดิจิทัลพนักงาน ปี 2569 (มีขั้นตอน "จัดทำแผนพัฒนาบุคลากร" เลยกำหนด)
- **HR-2569-002** ปรับปรุงกระบวนการ Onboarding พนักงานใหม่

## สิ่งที่ควรลองตามลำดับ

1. **ภาพรวม** — ดูการ์ดสรุป: โครงการรันอยู่, ขั้นตอนเสร็จ, เลยกำหนด, ใกล้ถึงกำหนด
2. กด **⏰ รันสแกนกำหนดเวลา** ด้านซ้าย → จำลอง cron 08:00 น.
   - งานที่เลยกำหนดจะถูกเปลี่ยนเป็น `Overdue`
   - แจ้งเจ้าของงาน + HR Manager (เมนู **การแจ้งเตือน**)
   - ไม่ส่งซ้ำในวันเดียวกัน (dedupe)
3. **โครงการ → โครงการพัฒนาทักษะดิจิทัลพนักงาน** → Checklist / Kanban / ประวัติ
   - เปลี่ยนผู้รับผิดชอบ/กำหนดส่ง/สถานะ → จะเป็น **ร่าง** (ขึ้นข้อความ “ยังไม่บันทึก”) **ยังไม่มีแจ้งเตือน**
   - กด **💾 บันทึก** ในขั้นตอนนั้น → จึง record ลง Audit trail และส่งแจ้งเตือน `Assigned` / `Due Date Changed`
   - เปลี่ยนสถานะเป็น `Done` แล้วบันทึก → HR Manager ได้แจ้งเตือน `Status Changed`
   - ปุ่ม **ทำเสร็จ** ในหน้างานของฉัน / Kanban เป็น action โดยตรง (บันทึกทันที)
   - ขั้นตอนที่ขึ้นกับขั้นตอนอื่นถูก **บล็อก** จนต้นทางเสร็จ
   - กด **รายการย่อย** เพื่อเพิ่ม/ติ๊กเช็คลิสต์ (เช่น “จัดทำร่างแผนเสนอผู้บริหาร”)
   - ครบทุกขั้นตอน → สถานะโครงการเป็น `Completed` อัตโนมัติ
4. **แม่แบบกระบวนการ → + สร้างแม่แบบ** → เพิ่มขั้นตอน (วัน, บทบาท, หลักฐาน, dependency)
5. **โครงการ → + สร้างโครงการ** → เลือกแม่แบบ ระบบสร้างขั้นตอนและกำหนดส่งอัตโนมัติ
6. **งานของฉัน** → เปลี่ยนผู้ใช้มุมซ้ายเป็น ธนา/จินดา เพื่อดูงานของแต่ละคน
7. **การแจ้งเตือน** → อ่านรายการ/อ่านทั้งหมด และเปิด-ปิดช่องทาง in-app / email
   (อีเมลเป็น dry-run: ดูได้ใน Developer Console ของเบราว์เซอร์)
